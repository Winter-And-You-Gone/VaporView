# VaporView

基于 Qt5 的导航系统可视化交互界面，用于实时监控 GNSS/RTK、IMU、气压计和温湿度传感器数据。

## 功能特性

- **多传感器数据采集**: 支持 GNSS/RTK (UM982)、IMU (HiPNUC)、PTB210 气压计、HMP3 温湿度传感器
- **实时数据显示**: 三列布局，GNSS 和 IMU 分两列显示详细数据，环境参数纵向紧凑排列
- **串口配置管理**: 下拉选择串口，自动扫描可用设备
- **采样频率设置**: 支持统一频率调整和单独频率设置 (1-20 Hz)
- **中英文切换**: 支持界面语言切换
- **全屏模式**: 支持 F11 全屏显示
- **数据导出**: 支持 CSV、JSON 格式导出完整数据
- **操作日志**: 实时记录操作和状态信息

## 数据字段

### GNSS/RTK (PVTSLN 协议)
| 字段 | 说明 |
|------|------|
| 纬度/经度/高度 | WGS84 坐标 |
| 北速/东速/地速 | 速度分量 |
| 航向/俯仰 | 姿态角 |
| 纬度σ/经度σ/高度σ | 位置精度 |
| 卫星数 | 使用/跟踪卫星数 |
| GDOP/PDOP/HDOP/HTDOP/TDOP | 精度因子 |
| 定向类型/基线长/截止角 | 定向信息 |

### IMU (HiPNUC)
| 字段 | 说明 |
|------|------|
| 加速度 X/Y/Z | m/s² |
| 陀螺仪 X/Y/Z | deg/s |
| 姿态角 Roll/Pitch/Yaw | deg |
| 四元数 W/X/Y/Z | - |

### 环境参数
| 传感器 | 字段 |
|--------|------|
| PTB210 | 气压 |
| HMP3 | 温度 (°C)、湿度 (%RH) |

## 依赖

- CMake 3.16+
- Qt5 (Core, Widgets)
- C++17 编译器

## 构建

```bash
cd VaproView
mkdir -p build && cd build
cmake ..
make -j$(nproc)
```

## 运行

```bash
./build/VaproView
```

## 默认串口配置

| 设备 | 波特率 | 参数 |
|------|--------|------|
| GNSS (UM982) | 115200 | N81 |
| IMU (HiPNUC) | 115200 | N81 |
| PTB210 | 9600 | E71 |
| HMP3 | 19200 | N82 |

## 支持的协议

### GNSS (UM982 RTK 接收机)
- PVTSLN 协议：定位定向信息

### IMU (HiPNUC)
- HI81: INS 数据包
- HI83: 扩展 IMU 数据包
- HI91: 浮点 IMU 数据包

### PTB210 气压计
- RS232C 串口通信
- `.P` 命令读取气压值

### HMP3 温湿度传感器
- Modbus RTU 协议
- 从站地址: 240 (0xF0)
