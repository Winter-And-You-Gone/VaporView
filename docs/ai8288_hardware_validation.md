# AI-8288 实机联调清单

适用型号：`AI-8288D92J0G71G71S2-24VDC`。

## 已按说明书实现

- 物理接口按 S2 模块处理：24 VDC 供电，RS485 `A` 对 `A`、`B` 对 `B`。
- 默认通信参数：站号 `1`、`19200` baud、8 数据位、无校验、1 停止位。
- Modbus-RTU 功能码 `03` 读取和 `10` 写入；一次读取不超过 32 个寄存器。
- 以主机轮询方式一次读取 8 路 `PV`（`0x0600`–`0x0607`）。
- 温控页面支持读取和设置当前 UI 中的通道参数、输入参数组、输出参数组和全局参数。
- 每次写入后立即用 `03` 回读相同寄存器；回读不一致即报告失败，防止 `Loc` 锁定时出现“设备应答但参数未生效”的假成功。
- Srun (`0x0845`) 保留设备读取到的原始 16 位值；只有用户明确选择说明书支持的 `0`、`15` 或 `9655` 且目标值发生变化时才允许写入，未识别值会被保留。
- Collector 会独立校验 Srun 写入目标；非法目标在任何其它全局寄存器写入前被拒绝。
- 写 `Act` 时只修改控制方向 bit 0，保留该寄存器的其它功能位；写 `Loc` 时只修改 UI 暴露的 bit 5，保留 bit 6/7。
- `OP` 只在 `At=3`（手动输出）时写入，自动控制状态只读取。

## 实机验证前暂不下发

- `Addr (0x0840)` 和 `bAud (0x0841)`：修改后设备会立即切换通信参数，说明书没有明确应答完成与切换生效的精确时序。当前可读取并显示，但即使页面值被编辑，写入全局页时也会跳过这两个寄存器并明确提示。
- `Srun (0x0845)` 的原始值 `1`：软件层误写风险已修复，页面会显示并保留未知值；`1` 的设备语义仍未确认，只有明确选择 `0`、`15` 或 `9655` 才会写入。
- `AFC` 校验位：当前连接固定使用说明书默认的 8N1。偶校验切换需要验证设备端生效时序和 PC 串口重新打开流程后再开放。

## 必须用实机确认

1. 断电后确认 RS485 A/B 接线、转换器隔离方式、参考地及屏蔽方案；不将 RS485 信号地与仪表 `24V-` 视为无条件必接。若无应答，断电后仅交换一次 A/B 复测。
2. 用默认 `COMx @ 19200, 站号 1, 8N1` 连接，确认能读到 `0x0853` 型号特征字和连续 8 路 PV。
3. 用已知温度点核对普通 PV/SP 的 `0.1 °C` 缩放和负温符号。
4. 逐页读取后只修改一个安全参数，确认软件显示“写入并回读确认”，仪表面板值同步变化。
5. 分别验证 `Loc` 未锁定和 bit 5 锁定两种状态；锁定状态下软件必须报告回读不一致，不能显示成功。
6. 在手动模式验证 `OP raw=25600` 对应 100%，并确认自动模式不会尝试写 OP。
7. 确认 `AAF` 五个报警锁定位的实际 bit 含义和组合值。
8. 确认 `Srh/SrL`、`CtI` 的时间单位与页面显示一致。
9. 记录 `0x0853` 型号特征字、`0x0854`/`0x0855` 机号高低字顺序以及最终显示格式。
10. 单独读取并记录 `Srun=1` 的设备实际语义，不要将其推断为自动运行；只有在现场明确选择说明书支持状态时才执行 Srun 写入验证。
11. 最后单独验证 Addr、bAud、AFC 的切换和重新连接；验证通过后再解除软件中的暂不下发限制。

高分辨率 32 位 PV 区（`0x0660` 起）没有用于当前页面。说明书对该区的字序、负值和小数缩放说明不足，普通 16 位 PV 已能覆盖当前 0.3 级 AI-8288 的常规显示与设置流程。
