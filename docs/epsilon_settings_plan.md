# EPSILON 分层设置接入计划

本计划基于 EPSILON/EPSILON2 手册、官方开发者配置文档、本地 MCU 配置例程与 FDIGroundStation 源码审查。设置继续位于现有“组合导航 → EPSILON”入口内，设备参数与本机连接配置分开表达。

## 分阶段范围

| 阶段 | 页面与能力 | 验收依据 |
|---|---|---|
| 第一阶段：常用设置 | 保留通信输出页，增加安装与天线、导航融合两个子页；提供按组读取、修改项写入、保存与回读、设备重启；安装角、天线几何、常用 AID 和动力学参数按资料及设备支持情况开放 | 未读值不能写入；未知参数不能当零；只写变化项；失败后退出配置并恢复数据流；本地/远端结果一致；旧天空端不能假成功 |
| 第二阶段：高级设置 | 扩展通信协议、波特率，增加高级设置页：滤波、量程、PPS、初始姿态/原点、输出参考点；增加参数快照导入导出与差异预览 | 按型号/固件核实枚举与单位；通信修改可重连；参考点与天线杆臂分别定义；导入不覆盖未知参数 |
| 第三阶段：校准及型号功能 | 增加校准与维护页；按需求实现调平、静态零偏、磁校准、双天线/里程计向导；支持相应型号的内置 4G/电台及外部辅助链路 | 校准有前置条件、进度、结果、失败恢复；设备型号不支持时不提供操作；需要实机证明配置生效及重启持久化 |

完整规划为五个内部子页，目前已创建通信输出、安装与天线、导航融合、高级设置、校准与维护。第一阶段、第二阶段的通用参数，以及第三阶段的静态维护、ASCII 磁校准与 D4G 内置差分配置已接入；缺少扩展协议的自动向导仍单独列为未完成，不显示假成功入口。工厂标定、算法内部参数和固件升级继续使用厂商工具。

## 第一阶段分工与接口

三个子 Agent 均使用 `gpt-6.1-sol`、`medium`：

1. 协议与设备：参数白名单、双语描述与单位、响应解析、ASCII 读写/保存/回读流程、采集器和配置服务、故障路径测试。
2. 界面：三个内部子页、未读/未支持/编辑/操作中状态、差异提交、中英文与主题、窄窗口及切页状态测试。
3. 会话与远端：现有异步设备会话、遥测操作编解码、天空端执行、超时和断连处理、旧版本拒绝与响应校验测试。

主 Agent 负责共享接口协调、主窗口接线、构建配置、集成审查、实际渲染确认、最终构建/回归与提交推送。各 Agent 拥有独立文件范围；构建、GUI 验证和 Git 交付集中执行。

参数模型使用 `EpsilonSettingsGroup`、`EpsilonSettingsOperation`、`EpsilonSettingsSnapshot`。值来源为设备查询；读取失败、参数不存在和合法的零值分别表达。描述符决定参数类型、单位、可写性、范围/枚举与重启要求。未确定枚举含义或取值依据的字段只读，不能猜测编码。

## 操作语义

- 读取按当前参数组执行，不在打开页面时自动扫描全部参数。进入配置模式可能暂时停止导航与数据输出，操作使用既有工作线程。
- 编辑从成功读取的值开始。设置请求在设备端再次核对当前值，只发送变化项；不把本机缓存视为设备实际状态。
- 保存确认、写后读取一致、需要重启是不同状态。未经过设备重启回读，不声称已经验证永久保存。
- 批次部分失败时明确报告；不假定设备具备原子回滚能力。恢复导航失败需要明确显示重连要求。
- 设备断连、后端切换或目标变化会使旧快照失效；晚到响应不能混入新会话。
- 录制期间不启动这些会中断数据的操作。远端操作必须校验设备、操作类型与参数快照，不能仅凭 ACK 判定成功。

当前白名单共 8 组、80 个描述项，其中 71 个允许按成功读取的设备原值编辑。描述项总数包含固件命名变体和只读项，不能当作所有型号都支持的参数数量。

| 参数组 | 项数 | 已实现内容与保护 |
|---|---:|---|
| 安装与天线 | 11 | 三轴安装角、主天线杆臂、副天线向量、航向偏角；设备计算的基线只读 |
| 导航融合 | 14 | 常用 GNSS、磁、静止、开机零偏辅助；通用与汽车动力学模型 |
| 通信 | 11 | COMM2–4 波特率及协议、COMM5 CAN 波特率、独立 NMEA 输出频率；COMM1 和 COMM5 协议只读，写前再查询当前协议，Main、未读或未知协议禁止修改 |
| 滤波 | 13 | LPF、BLP、两级陷波；频率非负、0 关闭，BLP 阶数 2–4；不套用滤波预设 |
| 传感器 | 4 | 加速度计、陀螺仪量程，GPIO2 PPS；GPIO1 是内部 GNSS 同步通道，只读 |
| 初始状态 | 10 | 三轴初始姿态、N/E/D 初始速度；原点经纬度四个拆分键只读，负数编码未确认 |
| 参考点 | 3 | 用户输出参考点 XYZ，IMU 坐标系、单位米；与 GNSS 天线杆臂分开 |
| 外部辅助 | 14 | 里程计类型、刻度、安装偏差、杆臂，以及外部航向、位置速度、SLAM1、汽车约束开关 |

通信协议依据 EPSILON `FDI_config.h` 和厂商 `Info.ini` 的共同枚举提供 0、2–24；Main=1 不作为可写目标，DroneCAN=25 因资料版本不一致未开放。选择外部协议和 AID 仅配置设备接收通道，不代表 VaporView 已产生外部位置/速度/里程计数据；实际发送端仍须提供对应帧、坐标、时标和质量信息。

参数快照以 JSON 导出成功读取的白名单原值，导入先校验结构、分组、字段、枚举、有限数值及实际编辑范围，再预览当前值与导入值的差异。未知项拒绝；未读、只读、不支持项跳过。导入仅填入当前组编辑器，不下发命令，也不自动保存或重启。文件限制为 1 MB，不接纳任意参数入口或账户凭据。

静态维护提供调平、加表静态零偏、陀螺静态零偏三个动作，分别使用 `#fimucal_level`、`#fimucal_acce`、`#fimucal_gyro`。依据手册物理页 68、219，这些命令不是六面标定；水平/静止前置条件在执行前确认。完整发送、动作 ACK、Flash 保存 ACK、退出配置与导航恢复分别检查。无动作回执显示“已发送，结果未验证”，没有虚构进度或完成状态；保存/退出/恢复失败仍保留可能已发送和待重启信息。维护不自动重发，完成发送保存后需设备重启并实机核对效果。

本地与远端复用同一维护协议逻辑和类型化结果。旧天空端、不支持或模拟设备明确拒绝；响应必须与请求动作匹配。录制或暂停录制、连接切换、其它设备操作期间禁止执行。成功重启清除旧读取值，后续重新读取；失败重启保留待核对状态。

## D4G 与磁校准接入

用户确认型号为 D4G。高级设置增加内置 4G 分组，共 9 个独立字符串字段，其中 6 个可按成功读取的原值编辑：NTRIP 服务器、端口、挂载点、账号、密码和 FDI 云鉴权码；IMEI、CCID 与差分模式编号只读。复用读取、保存及重启按钮，不新增第六个子页。官方 `RTCM_TYPE` 表格写 NTRIP=2，示例却使用 3；因此模式暂只展示实际原始编号，不混用 `BASE_STATION_SOURCE`，不自动切换 NTRIP/云模式。

DGNSS 使用 `#fdgnss get/set`，支持全角冒号、ASCII 冒号和等号回复，按完整字段名解析、冲突值或错误回复拒绝。只写已读且变化的字段，检查保存 ACK、写后回读与退出配置；失败保留部分变更及待重启事实。ASCII token 接口限制为可打印非空白字符与应用长度上限（不是硬件存储容量承诺）；设备不支持或拒绝时明确报告。账号、密码、鉴权码遮罩显示，不写 QSettings，不纳入普通参数快照。内置差分配置与主机 NTRIP 转发仍为不同路径，尚未证明设备实际联网或 RTCM 已接通。

校准页增加磁力计 2D/3D 和请求退出按钮。官网配置指令实际提供 `#fmagcal2d`、`#fmagcal3d`，不需要推断 MAVLink 扩展帧；之前仅依据厂商自动校准模块判断缺少启动契约的结论不适用于此 ASCII 入口。2D 按完整 `Now: N percent` 报告读取百分比，100 才作为设备完成报告；3D 按同次报告的有限非负拟合误差小于 3 和等级 `High` 判断，不能把旧误差、新等级或 NaN 拼成完成。ACK 仅表示开始，不作为完成；流恢复失败仍整体失败。

开始前读取实际支持的磁融合键（包括 `MAG_3D` / `MAG_V` 命名变体），保留原值并关闭融合，完成或失败后尝试恢复原融合值、保存、退出配置并恢复导航。两个别名都存在且原值冲突时拒绝开始。真实进度在本地和远端异步更新；300 次一秒轮询有界，请求退出只表示尝试 `#fdeconfig`，不保证固件已停止校准。断连、切换目标和停机取消当前任务，旧回调隔离；取消后恢复仍须实机确认。静态维护继续不虚构进度或物理效果。磁设备自动保存报告与静态 `#fsave` ACK 分别表达，完成后重启核对。

只读设备信息从 EPSILON `MSG_VERSION`（0x39，固定 40 字节）接入硬件/固件名称、原始版本编号和序列号，本地、远端及本地 IPC 均保留。没有收到版本报文时明确显示未读取，不更改设备包率，也不由通用名称推断 D4G 型号或猜版本编号的分段编码。依据 [版本报文定义](https://doc.fdisystems.cn/developers/02-fdilink/03-data-packets/MSG_VERSION.html) 与 MCU 的 EPSILON 结构一致。

| 能力 | 已核实依据与当前覆盖 | 缺失条件 |
|---|---|---|

| 内置差分模式切换及电台型号 | D4G 的可读写字符串已接入；电台属于其他型号，未给 D4G 添加无依据的电台按钮 | 当前固件的 `RTCM_TYPE` 明确映射；电台型号及命令契约 |

| 外部辅助输入生产与转发 | 设备端口协议及 AID、里程计等参数已提供 | 实际外部数据源、坐标系、时标及质量信息；不能用测试数据冒充硬件输入 |

本地厂商源码只提供自动模块调用方，未找到 `FDI_MODULE_CMD/DATA` 生成定义或 dialect XML。官方 [双天线教程](https://doc.fdisystems.cn/developers/fdigroundstation/2/dualAntCal.html) 与 [里程计教程](https://doc.fdisystems.cn/developers/fdigroundstation/2/%E9%87%8C%E7%A8%8B%E8%AE%A1%E6%A0%A1%E5%87%86.html) 给出厂商工具操作及运动条件，没有给出可复用的开始/停止帧。取得当前固件配套协议后才能完成这些自动向导。工厂标定、算法内部参数及固件升级仍是原计划明确暂缓项。

软件实现与模拟测试不能代替实机效果。固件版本和是否接在本机尚待补充；不自动向设备下发校准、恢复出厂或配置。实际联网、重启持久化、磁校准效果与取消恢复检查见 [实机验证备忘录](epsilon_hardware_validation_memo.md)。
