# VLP1 20261017 主机扩展接入与实板检查

## 对照依据

本次对照本机 `Vapor_Radar_App_V2` 的 `9f45e49f8ffb10d64248d637bee8facd999e3666`，
以 `Docs/protocol/HOST_EXTENSIONS_20261017.md`、对应 RTL 和 HDL 测试为协议依据。
该提交包含新增 RTL，但其验证记录没有新的 Vivado 实现、BIT 生成或实板验收结果。
上位机支持不代表用户设备已经烧入新固件。

## 能力与入口

必须读取 GET_CAPABILITIES 的扩展字；模块旧版本号不代表已具备新增能力。
旧固件的扩展字 `0x01` 继续使用原接口，新固件完整扩展字为 `0x3F`。

| 扩展位 | 功能 | 上位机入口与行为 |
| --- | --- | --- |
| 0 | RAW schema 2 | 原有采集、记录、回放接口 |
| 1 | AI8 八通道扫描、schema 3、定向设温 | FPGA 传感器页切换扫描；各通道按 tag `0x0468` 更新；完整参数页 SP 可逐通道设置 |
| 2 | AI8 参数事务 | 现有 AI8 通道、输入组、输出组、全局参数页；FC10 后实际 FC03 核对 |
| 3 | EPSILON MAIN ASCII / RTCM 邮箱 | 现有导航参数、DGNSS、杆臂、包频率页面；RTK 页选择 MAIN 封装或外接 RS422 |
| 4 | 独立 RD105，source `0x0048` / page `0x6800` | 首页及设备配置连接、标题栏总连接、现有 RD105 参数页及当前测量通道/通用参数读取按钮 |
| 5 | DLIA 截止频率 | FPGA DLIA 页选择 100 / 250 / 500 / 1000 / 2000 / 5000 / 10000 Hz，显示生效值 |

连接单个设备只打开 FPGA 和该设备；首页标题栏总连接依次显式启用各个支持的设备。
RD105 不通过旧广播掩码隐式启用，也不映射为 AI8。
RAW 上传、WMS 和 DAC 保留原来的独立控制行为。

## 参数事务与结果

- USB 队列串行执行扩展事务；参数页在自己的工作线程等待结果，GUI 不等待 USB。
- VLP RESP 仅表示 FPGA 接受命令。AI8 / RD105 参数必须同时核对有效位、完成计数、设备错误及实际读回字节。
- 失败、超时、断连和读回不符均不能报告成功，不自动重发设备写入。
- EPSILON 的 ASCII 响应按原样交给已有厂商命令解析器；邮箱返回成功且响应为 `#ERROR` 时，设备操作仍失败。
- RTCM 输入按完整帧验证长度及 CRC24Q 后提交；MAIN 的 FDILink 分片由 FPGA 完成，RS422 输出原始 RTCM。
  转发队列有上限并丢弃超过三秒的未发送帧，失败帧不重发。UART 完成不表示接收机已经应用差分。
- 原始 USB、命令、配置快照和源数据沿用 FPGA 会话归档。AI8 schema 3 带通道号；RD105 测量通道由对应硬件配置快照还原。

## 必须保留的设备限制

1. RD105、HMP、AI8 共用生产板 CON19 RS485 总线。RD105 须先通过原生接口设置为 **19200 / 8N1、地址 2**，
   HMP 默认地址 240，AI8 默认地址 1。改 FPGA UART 配置不会修改仪表自身波特率。
   参数读取按 FPGA 显式配置的测量通道确定读取范围，不假定每台仪表都具备第二通道；选通通道 2 后可读取两通道参数。
2. RD105 恢复出厂只允许显式 opcode 3、地址 0、数量 1、线序数据 `00 01`。结果 6 仅表示收到写 ACK，最终状态未验证；
   下位机停止轮询，需按恢复后的仪表通信设置重新连接。无 ACK 时连该结论也不能成立。
3. AI8 恢复出厂仍无厂商命令依据，继续禁用；参数锁 Loc 和 FPGA 模块复位不等于仪表恢复出厂。
4. 地址、波特率、通信格式写入可能导致独立读回超时，应显示结果未知。不得自动重试。
5. EPSILON 邮箱 ASCII 格式强制以 `#` 开头，不能发送厂商重启步骤的独立 `y` 确认。
   因此不通过该邮箱启动不完整的重启流程；参数保存后按页面提示通过设备原生方式重启并重新连接。
   长时磁标定所需的持续被动接收也不由此单次命令邮箱保证；该操作在发送前返回不支持。
6. 外接 RS422 需实际接到 EPSILON 空闲且配置为 RTCM 的端口，波特率一致；保留内部 GNSS 预留端口。
   MAIN 封装路径不要求改写这些内部端口。
7. 非默认 DLIA 截止频率要求 ADC 实际采样率匹配固件编译标称值；本上位机的当前 AD4630 路径为 1 MHz。
   COMMIT 在停采排空后应用，切换清除滤波历史；旁路模式保持原定义。
