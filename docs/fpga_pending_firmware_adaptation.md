# AI-8288 八路轮询固件联调交接

## 上位机行为

地面端与 SkyCore 已移除 AI-8 八路轮询开关。设备声明 `FpgaExtensions::Ai8Scan` 时，应用 AI-8 配置或启用采集前，控制器将 `0x6668` 设为 `1` 并校验读回值。旧固件未声明该能力时，控制器跳过扫描模式写入，继续通过 `0x661c` 选择单个通道。

## 待固件适配

当前支持扫描的固件上电后 `0x6668` 默认为 `0`（单通道）。请将复位默认值改为 `1`，或固定执行八路扫描并兼容写入及读回 `1`。保留 `0x66fc` 能力报告和 schema=3 通道数据。`0x662c` 以毫秒表示整轮扫描周期，通道编号、缓存和时间戳应对应同一次通道采样。

## 到板验收清单

- [ ] 冷启动及复位后，在控制器首次写入前读取 `0x6668 == 1`，核对 `0x66fc` 与设备声明的 `Ai8Scan` 能力。
- [ ] 跳过主机对 `0x6668` 的写入并启动采集，连续记录多轮 schema=3 数据。每轮应覆盖通道 1–8，同一通道的更新间隔应符合 `0x662c`。
- [ ] 依次通过 `0x6698` 选择八个通道，核对 `0x66a0..0x66b4` 的状态、数值和时间戳与对应通道上报一致。
- [ ] 在轮询期间交错执行缓存读取、设温及参数页读写，确认应答、读回和后续采样均对应目标通道。
- [ ] 连接未声明 `Ai8Scan` 的旧板，选择通道 8 并应用配置。确认 `0x661c == 8`，采集正常，命令记录中无 `0x6668` 写入。
