# 直连与 FPGA 中转 UI 适配及功能缺失

## 修复计划与验收条件

| 顺序 | 项目 | 验收条件 |
|---|---|---|
| 1 | 远程直连 / FPGA 路径切换 | 经现有数传 TCP 下发配置，切换不关闭数传；等待最终应用结果，拒绝时恢复已确认的路径；超时读回天空配置，不自动重发 |
| 2 | 两页来源与参数显示 | 环境气压固定 PTB210、环境温湿度固定 HMP；BMP390/SHT45 为独立内部设备，两页无来源选择 |
| 3 | 首页连接入口与状态 | 本地与远程均可从首页建立 FPGA 连接，再启用指定设备；最终连接读回成功才继续，失败或超时不自动重试；区分通道启用与有效测量 |
| 4 | AI8 和 EPSILON 操作能力 | 保留数据显示；不支持的参数操作在 UI 和设备会话两层禁止，不提示用户改接串口 |
| 5 | RTK / RTCM | FPGA 模式禁用启动、串口测试、串口探测和参数下发；切换进入 FPGA 时停止原 RTK / GGA 服务；保留 NTRIP 配置供直连使用 |
| 6 | 回归与交付 | 覆盖本地/远程 × 直连/FPGA，Release 构建、相关回归和跨 SkyCore 全量回归；无实板时仅报告软件验证 |

## 共用入口的行为

单设备连接在 FPGA 未连接时只执行 USB 打开、PING、能力和版本核验、寄存器读回，再对目标设备完成参数下发与启用；不执行全局采集复位或其他传感器的停启恢复。已运行的其他设备保持运行，原先停用的设备保持停用；状态按板上实际 CONTROL 显示，不把建立 USB 会话当成所有设备刚完成连接。本地 FPGA 模式的标题栏连接在握手成功后，按序启用 PTB210、HMP、EPSILON、TFA1500、AI8、BMP390、SHT45 及 ADC/DLIA；已经启用且没有参数草稿的设备保持运行。每步等待真实读回，失败或主动断开时终止剩余操作，不自动重试。RD105 尚不受协议支持；RAW、WMS/DAC 保留独立控制。FPGA 页显式连接仍只恢复原先已启用模块。

远程单设备连接使用现有 `connect` 操作携带布尔字段 `recover=false`；省略该字段时保留原恢复策略。新版 Ground 与 SkyCore 应同步更新；旧版 SkyCore 会拒绝该新字段，不自动退回可能重启其他设备的连接操作。这个策略不增加 FPGA 命令或修改 VLP1 固件协议。

首页与设备配置页的逐设备按钮复用同一个路由入口。本地直连打开本机设备；远程直连由 SkyCore 打开天空端设备。本地 FPGA 打开 USB 并启用指定 VLP1 source；远程 FPGA 通过数传 TCP 请求 SkyCore 建立 USB 会话，再启用指定 source。SkyCore 是远程 USB 的唯一所有者。单设备停用不关闭 USB 或数传。

“通道已启用”来自 FPGA CONTROL 寄存器，不能证明传感器在线或测量有效。测量有效性、数据新鲜度和数据帧频率分别由实际测量及质量信息决定。

首页波形原始信号按钮控制 RAW 上传；二次谐波按钮控制共同 ADC/DLIA 采集。停止共同采集也停止 RAW，两个按钮不是两个独立的采集引擎。

## 配置模型与当前写入边界

设备配置页在 FPGA 路径直接显示波特率、频率输入框，不再提供逐字段“设置”按钮。目标设备连接时输入框禁用；断开该设备后可修改 PTB/EPSILON/TFA 波特率，以及 PTB/HMP/BMP/SHT/AI8 轮询频率（Hz）。编辑原文仅在内存暂存，周期读回不覆盖草稿或改写尚未输完的小数；重新连接时才换算为寄存器参数，下发并核对参数，确认成功后启用通道并锁定输入框。失败时保留草稿，不自动重试。本地通过 USB 提交；远程通过已有数传 TCP 请求 SkyCore 提交，不另开设备串口或第二条天地链路。直连预设、本地与远程草稿、界面测试模拟草稿均独立保留；关闭程序不保存未提交草稿。I²C、固定波特率及设备自身决定的输出频率仍显示只读说明；没有草稿或有效读回时不冒充实际值。

远程重新连接使用受限的 `sensor` 命令，`enabled=true` 时可携带 `baud` / `poll_ms` 草稿，SkyCore 在同一事务内完成写入、读回和启用。底层 `sensor_config` 参数事务保留。需要天空端同步部署本版本 SkyCore；旧版 SkyCore 会拒绝新增字段。这是上位机软件协同更新，不要求为这些现有寄存器升级 FPGA 固件。

本地与 SkyCore 共用 `FpgaDeviceController`，USB 枚举、连接/断开、配置分区提交、采集、独立 WMS/DAC、传感器启停、波特率/轮询设置、RAW 和 AI8 设温均有远程入口。USB 已打开但握手或版本核验失败时，两端仍允许手动刷新只读寄存器，并继续禁止参数写入；刷新不会自动重连，也不能绕过未完成的连接恢复。源码更新和本机生成新版 SkyCore 不代表天空端机器已部署，实际远程运行时需替换天空端程序。

设备配置页在直连路径显示“启用”列，编辑直连启动预设；FPGA 路径统一显示“状态”列，所有复选框仅显示实际 CONTROL 寄存器读回，传感器和 ADC / DLIA 均使用同行右侧操作按钮启停。尚无有效读回时不勾选并提示状态不可用；RD105 不勾选并提示当前协议不支持。命令确认前保留已读回状态，不能把操作受理或有效测量当成通道启用。切回直连路径恢复原有预设，FPGA 状态不会写入本地或天空端直连配置；模拟器使用同一显示规则。

本地与 SkyCore 共用这些现有寄存器的参数事务：先读取目标通道实际启用状态及模式约束，仅暂停目标通道，逐项写入并核对实际读回，再启用目标通道并核对 CONTROL。底层独立 `sensor_config` 请求仍恢复目标通道原状态。采集和其他设备不重启。基本波特率/轮询参数为直接生效寄存器；BMP390 高级配置按固件要求提交，HMP 压力补偿使用带确认计数的 SENSOR_ACTION。写入失败或结果未知时停止事务，不自动重发、不盲目恢复通道，显示已读回状态并要求刷新核对。

标题栏统一连接逐个启用受支持的 FPGA 通道，逐设备输出日志：CONTROL 读回后提示通道已启用、等待有效数据；收到结构、CRC、设备在线及测量有效性均通过的数据后输出连接成功。等待超时输出连接失败，最短 8 秒，轮询设备按实际间隔保留至少三轮加 5 秒；事务中止时对受影响设备记录失败原因。周期数据和定时读回不会反复刷连接日志，主动断开清除等待结果。ADC / DLIA 的成功说明采集 CONTROL 已读回，RAW 上传仍独立控制。未启用通道及尚不支持的 RD105 不冒充已尝试连接。远程 SkyCore 使用现有数传 `LogEvent` 将这些结果发送到地面日志卡片，无需增加通信链路或 FPGA 固件功能。

PTB 波特率范围 1200–19200，EPSILON 为 9600–6250000，TFA 为 115200–6250000（当前 100 MHz 固件）；TFA 高频模式要求至少 500000。轮询间隔范围 1–3600000 ms；PTB 连续输出模式不应用轮询间隔，SHT 加热模式要求至少 12000 / 1300 ms（由当前加热档位决定）。AI8 串口固定 19200；其地址、通道、超时和重试仍在 FPGA 页配置。TFA 输出频率由实体设备决定；EPSILON 接收掩码不等于设置实体设备的包频率。

波特率设置控制 FPGA UART，需与实体传感器串口设置匹配，不能据此声称 EPSILON 等设备内部参数命令已经支持。轮询间隔是请求节奏，不等于首页从实际收到的数据帧统计的频率；AI8 间隔还包含每轮完成后的等待。界面测试仅修改内存中的模拟寄存器，不能作为实板写入证据。

2026-10-14 补正：此前读取列表只覆盖传感器公共控制/状态及 AI8 专用字段，漏读 PTB `0x6010`、EPSILON `0x6210`、TFA `0x6510` 波特率，以及 PTB `0x6018`、BMP `0x6314`、SHT `0x6414` 轮询间隔，因此已连接时仍可能显示“—”。现已补齐连接核验、手动刷新和定时刷新读取，并通过现有 SkyCore 状态转发到远程页面；模拟器与界面测试模式也提供对应值。未连接或状态过期时仍不以直连预设冒充实际值。SHT45/BMP390 使用 I²C，没有串口波特率。

设备配置页“启用”复选框的边框与勾选标记使用主题主色，FPGA 只读状态仍保持可辨识的主题颜色，不改变直连启动预设或实际通道启停逻辑。

设备配置表已移除旧“来源”列的空占位，操作列紧接状态列。FPGA 的 ADC / DLIA 行从 `0x4014` 显示两路共用的实际 ADC 采样率（Hz），提示中显示 `0x504C` / `0x514C` 的 DLIA 实际输出率；这些与波形帧频、RAW 上传速率不同。采样率及独立解调率仍在 FPGA 参数页修改。该行状态框独立于直连 TCP 启动预设，按 ADC/DLIA CONTROL 读回显示是否存在启用通道；右侧操作按钮复用现有两路采集 START / STOP 和排空事务，最终读回后更新状态框。本地 USB、远程数传 TCP / SkyCore 使用同一路由，RAW 上传继续独立控制，无需新增 FPGA 固件能力。

环境来源选择已移除：PTB210 `0x0040` 固定提供环境气压，HMP 固定提供环境温湿度；BMP390 `0x0043` 和 SHT45 `0x0044` 仅用于内部环境，各自独立连接。FPGA 已接入真实 HMP source `0x0041`；不以 SHT45 或直连 HMP3 预设冒充实际 FPGA 环境温湿度。

## 当前 VLP1 功能缺失

依据同级 FPGA 仓库 `Docs/protocol/FPGA_HOST_PROTOCOL_V1.0.md`、`HOST_HANDOFF_20261001.md` 和 VaporView 当前控制接口；独立的 VFLP 设计稿不是当前实现依据。

| 缺失项 | 当前已支持 | 下位机需要补充的能力 | 上位机处理 |
|---|---|---|---|
| AI8 完整参数页 / 恢复出厂 | 测量 PV、SP 等状态；目标温度设置及仪表读回确认 | 明确的通道/组/全局参数读写、恢复出厂命令，仪表响应与读回结果、超时及错误语义 | 参数页命令禁用并说明 VLP1 不支持；FPGA 页轮询、设温流程可用 |
| EPSILON 参数命令 | FDILink 接收、导航/姿态/状态数据显示 | 包频率、安装杆臂、融合参数、GNSS/DGNSS 设置、校准/重启等下行及参数回读 | 参数操作禁用，保留导航显示；不使用另一个串口绕过 FPGA |
| RTCM 注入 EPSILON | 直连模式的本机串口输出或数传到 SkyCore 转发 | VLP1 RTCM 注入命令、目标 UART、分片/流控、写入统计及设备/传输失败语义 | FPGA 模式阻止启动和串口旁路；远程天空端继续拒绝此操作 |
| RD105 经 FPGA 接入 | HMP3 已接入 source 0x41；AI8 为独立温控器 | RD105 需要独立 source、版本、命令及数据 schema | 不把 AI8 冒充为 RD105；RD105 连接入口禁用 |

缺失功能不能通过取消灰化实现。需先扩展当前 FPGA/VLP1 契约和固件，再补上位机命令、质量/错误处理与回读测试。

## FPGA 会话波形与记录统计

FPGA 新记录复用 `raw/waveform.dat` 保存双路完整 H1/H2，不再生成 `raw/fpga_vlp1.dat` 或 `sensors/fpga_frames.jsonl`，不保存 ADC RAW、I/Q 或转发通信字节。查看器默认 DLIA0 的 H2/H1，按需从当前帧 H1/H2 计算，不在 Session 中另存归一化波形。每周期完整归一化峰值/位置/质量保存到 `sensors/waveform_features.csv`，可直接加载趋势。下拉框提供 DLIA0/1 的 H2/H1、H1、H2，各自独立时间轴；变长周期按记录中的实际点数处理。历史 FPGA 档案继续支持 ADC RAW 及已有 I/Q 分量回放。

记录页显示“保存 H1/H2（必选）”，取消“记录 RAW”选项。原始信号的实时采集/显示操作保留；“打开离线记录”进入现有数据查看器，新记录“导出记录”复用原始数据解析页。归一化算法、无效参考规则及 FPGA 配置写入标准配置/元数据，配置变化和连接/暂停恢复分段写入事件日志。

`RAW WAVE` 统计共用 waveform.dat 中的记录，FPGA 的每个周期占一条记录和一条特征行；缺片、溢出等周期只存质量标记，曲线留断点。两路均完整记录，不按 UI 默认通道筛选，也不重复加上旧 FPGA 归档计数。地面本机和 SkyCore 均从 UI 合并/预览抽稀之前接入；远程有限预览可携带完整周期峰值，旧版发送端仅有预览时保留预览标识。详细改造对比见 [Session 接入说明](fpga_session_recording.md)。

## 实机检查

- 数传连接保持期间往返切换两种设备路径，核对天空端实际路径及设备关闭/打开顺序。
- 从远程首页连接单个 FPGA 设备，确认只存在一个 USB 所有者；USB 连接失败时不继续发设备启用命令。
- 两页均无环境来源切换；PTB 环境压力、BMP 内部压力、SHT 内部温湿度独立启停与显示，内部传感器不覆盖 session 环境字段。
- 通道启用但拔掉传感器时，不把启用状态当作有效测量。
- FPGA 模式点击或直接调用禁用操作，不打开本机/天空端旁路串口；返回直连后恢复原配置及可用操作。
- 本地/远程确认连接中的设备字段禁用，逐设备断开后编辑波特率与轮询频率，确认编辑期间没有参数 WRITE、周期读回不覆盖草稿；重连时核对参数 WRITE、READ_RESP 与最后的启用动作，其他通道、采集和数传不重启。
- PTB 改波特率时检查停用后的 UART 收尾；STATUS BUSY 在停用态仍为 1，软件使用 50 ms 收尾等待，写入拒绝仍终止事务而不重发。EPSILON 自动恢复 UART 占用期间的拒绝也需现场检查。
- 注入写拒绝、读回不一致、USB/数传中断，确认不提示成功、不自动重发，刷新后展示实际参数和通道状态。

完整现场验收及凭据/原始证据保留要求见 [FPGA 实机验收清单](fpga_hardware_validation.md)。

### 下位机功能缺失：AI8 八通道自动轮询

AI-8288 仪表有八个通道，但当前 FPGA 只按 `0x661C`（1..8，默认 1）轮询一个选定通道。`ai8_poll_core.v` 的七次 FC03 请求均使用该 channel 计算地址，`ai8_modbus_rs485.v` 没有扫描通道递增逻辑。协议第 7/8 节的 source `0x0046` / schema 2 快照只含一组 PV/SP/SV/OP/报警等 TLV，没有通道号；`0x661C` 只能在 AI8 禁用时修改。VLP 模拟器遵循这套单通道协议，因此默认只有通道 1 有数据，其余显示“---”。这与直连串口的八通道采集能力不同。

上位机已经根据确认的 `0x661C` 将样本放入对应通道，本地 `FpgaDeviceController` / `FpgaSensorAdapter` 和远程 SkyCore 均保留八元素温度数组，首页概览支持显示八个槽位；不是只读取数组第一个元素。本轮增加切到通道 8、读回寄存器、启用后接收 VLP 快照并显示到首页第 8 槽位的回归，其他未采集通道保持无数据。

若要求 FPGA 模式自动持续更新全部八通道，需要固件增加 1..8 轮询和各通道独立快照/错误状态，并在每条测量记录中携带明确通道号（扩展 schema/TLV，同时保持旧单通道协议兼容）。设温命令的目标通道、请求和确认也须保持对应。不能在上位机后台反复停用、改写 `0x661C`、再启用来冒充该能力，以免干扰当前轮询和设温事务。

首页三项内部环境指标已改为横向单行，设备温控概览恢复与其他卡片相同的标准标题栏高度。


## 2026-10-15 上位机遗漏能力补齐

依据当前 VLP1 RTL，逐项接入以下能力；本地与 SkyCore 共用控制器、解码、参数校验和会话格式。未接实板，软件回归不能替代现场验收。

| 顺序 | 接入内容 | 行为与边界 |
|---|---|---|
| 1 | HMP3 source 0x41 | Modbus RH/T F32 解码，首页环境温湿度、Session 快照、逐设备连接日志、固定 19200 波特率、轮询及地址/测量掩码；SHT45 仍为内部温湿度 |
| 2 | EPSILON 记录及 PPK | 0x1200 计入 EPSILON；0x77 原始观测逐包组装到现有 ObservationStore，不经过 50 ms 显示合并；缺包和 CRC 错误保留诊断，不伪造完整历元 |
| 3 | 管理状态/事件 | 0x1400 系统、0x1401 模块、0x1402 新错误、0x1201 同步、0x1300 运动完成：保留原帧及快照，状态显示于记录与诊断，错误/运动日志经数传传回 |
| 4 | DLIA 低通旁路 | 模式 2/3 为固件支持的正常模式，6/7 打开旁路；模式与线格式分别处理；分片点数 1–256 |

| 6 | 离线波形 | ADC0/1、DLIA0/1 与各可用分量可选择；无 I/Q 的归档不生成 I/Q 选项 |
| 7 | 高级控制 | 传感器高级字段、ADC CNV/BUSY/周期点数、分通道启停、同步控制/GNSS 标签、步进电机、模块复位/清错、传感器 FIFO、HMP 补偿、TFA 命令、看门狗和上传仲裁 |

高级传感器字段放在 FPGA 页“高级控制”，在设备断开时编辑，保存到本地/远程各自的目标配置，逐设备连接时下发并逐项读回；周期读回不覆盖修改。未编辑字段沿用硬件值。支持 PTB UART 格式/连续模式/超时，HMP Modbus 地址和 RH/T 掩码，EPSILON 接收过滤/原始观测转发，BMP 地址/OSR/ODR/IIR/电源模式，SHT 重复精度/加热模式，TFA LF/HF/超时/静默/帧间隔/尺度/无效状态掩码/版本命令。掩码和 UART 格式码遵循当前 RTL；HMP 环境完整数据需要温度和湿度两项均可用。

高级动作必须显式操作：连接不启动电机，配置电机参数后停用驱动；相对脉冲为有符号 32 位。电机频率/脉宽/方向建立时间由 100 MHz 当前 RTL 约束，无加减速控制。分通道采集走固件 START/STOP_ACQ，同一通道组包含 WMS/DAC/ADC/DLIA，保留另一组；普通首页停止采集仍沿用原有语义。ADC0/1 共用采样率/CNV/BUSY 时序，不能配置成两套独立时序。

看门狗显式设置为 0 关闭；启用至少 30000 ms，上位机每秒发送喂狗；断开/进程退出停止喂狗，固件按其自身看门狗语义处理。上传仲裁模式、高水位和高优先级突发上限均读回确认。维护失败不自动重发。

仍需要下位机扩展：AI8 自动八通道扫描及明确通道标识、完整 PID/组/全局参数与恢复出厂；EPSILON 设备参数命令/RTCM 注入；独立 RD105；可变 DLIA 低通截止频率。当前共享 ADC 时序属于硬件约束，不标成上位机漏接。
