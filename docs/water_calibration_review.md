## 完整链路审查结论

- FPGA 控制器先通过 `normalizedCyclePeak` 计算完整周期峰值，再发 `harmonicCycleReady`；记录服务直接接收完整周期。`harmonicFeatureCsv` 复用 `normalizedSecondHarmonic`，在整个有效区间计算 `max_i(H2[i]/H1[i])`。定标只读现有特征，不取 `max(H2)/max(H1)`，不从抽稀预览重新取峰。
- `InvalidReference=1` 表示无效采样点被跳过，仍有有限峰值时周期可用；其它质量位、无有效峰值或无效索引不用于拟合/有效预测。实时、记录、历史读取与定标规则一致。现有 CSV/DAT 格式和 FPGA 协议未改。
- 去重键仍为 manifest 的 Session 身份、通道和原 waveform sequence；不按峰值、时间戳或 cycle ID 去重。独立同浓度/同峰值测量保留；复制 Session 重导不累计。暂停恢复即使复用 cycle 和时间，也保留新 sequence/segment 对应的独立记录。没有 manifest 身份的旧文件仍按规范路径回退；若需要无歧义的跨设备合并，应另行批准兼容的 Session UUID 方案。
- 波长到 DLIA 的物理映射仍由用户明确选择，软件不能验证真实接线。816/1368 的 active 引用独立，禁止同时映射到同一 DLIA；模型输入单位不自动换算。存储采用不可变快照、追加修订、锁、并发摘要检查及 `QSaveFile` 原子替换。原子写入已满足本轮失败保护；备份/恢复 UI 仍在后续清单，不新建重复记录系统。
- 编辑、删除、排除后，当前拟合显示和残差失效，需要重新拟合；旧参数保持其原始输入与计算含义。新版本不会覆盖旧模型，结果保存具体参数 ID 和数据集修订，而非可变 active 引用。启停保存成功后才替换内存库；计算任务使用完整库快照。
- 对三点 `(R,C)=(1,2),(2,4),(3,5)` 独立核对：`a=3/2`、`b=2/3`、`R²=27/28`、`RMSE=sqrt(1/18)`，中点残差 `1/3`。有效范围两个端点可用，端点外一个 ULP 即拒绝外推。R²/RMSE 仅描述训练拟合，不判定仪器精度。
- 导入、拟合、库读写、整批计算/导出在 `QtConcurrent` 工作任务中完成，UI 只在所属线程应用结果。页面销毁时回调随 context 断开，工作任务只持有值副本；回归覆盖任务未完成时销毁页面。用户已发起的原子保存可在关闭页面后完成，不承诺中途取消写入。

## Session 生命周期与产品范围

当前功能要求**用户选中一个完整的本地 Session**，可正在录制、暂停或已经结束；不要求当下处于录制状态。跟随是每 2 秒检查所选文件，**不是自动订阅最新录制任务**。新建录制或切换其它主窗口页面不会自行更改所选目录。

暂停期间没有新增周期，恢复后读取新记录；停止后只读封存文件。页面隐藏/显示复用同一个 timer，没有新增 FPGA 订阅。跟随每次重算所选 Session 的快照，不向 Session 写入浓度；JSON 是用户显式导出的结果快照，保留当时的具体模型/数据集/源记录。参数切换后当前表重新计算，先前导出文件仍可重现旧版本含义。

无来源 Session 时显示错误并清空当前结果，不产生有效浓度。本轮不增加无 Session 数据流或浓度 CSV。是否要求首页在未录制时持续显示浓度、是否自动跟随新 Session、是否自动持久化浓度，以及历史重算是否允许换参数，仍需产品确认。大 Session 的增量读取/取消机制也是后续优化点，当前导入和计算会处理完整特征文件。
