# FPGA 模式遥测频率字段与悬停说明

日期：2026-11-12。

状态：已在 1.0.28 实现六项展示、悬停说明、FPGA 来源映射及过期处理。采集周期频率按下述实现边界显示“不可用”：现有协议没有远端真实周期计数与时间窗，不能用特征接收率替代。

## 展示范围

远程 FPGA 模式的频率区域只展示以下六项，按此顺序排列。不增加“ADC 原码预览”项。ADC 原码与 H1/H2 是不同数据，不能因本区域不展示 ADC 而改变其已有采集、上传或记录功能。

| 字段 | 统计含义 | 建议鼠标悬停提示文案 |
| --- | --- | --- |
| 基础遥测 | 地面端实际收到的基础遥测消息频率。 | 地面端每秒收到的基础遥测消息数，包含导航、环境等设备信息。它不是各传感器的采样频率。 |
| 遥测状态 | 地面端实际收到的天空端状态消息频率。 | 地面端每秒收到的天空端状态消息数，用于更新设备连接、记录及系统状态。它不表示波形采集频率。 |
| 原始波形预览（H1/H2） | 地面端实际收到的完整 H1/H2 预览频率；“原始波形”按本项目约定指 FPGA 输出的 H1/H2，不指 ADC 原码。 | FPGA 输出的 H1/H2 波形预览。为节省远程带宽，预览可抽稀；此处显示地面端每秒收到的完整预览数，不是 ADC 采样率，也不代表传输了全部原始点。 |
| 归一化二次谐波预览 | 地面端实际形成或收到的有效归一化二次谐波预览更新频率。不能以 UI 重绘次数计数。 | 由同周期 H1/H2 计算得到的归一化二次谐波形状，通常为 H2/H1；仅 IQ 格式使用幅值比。显示每秒有效预览更新次数，横轴为周期内采样位置，不是逐周期峰值趋势。 |
| 波形特征值 | 地面端实际收到的 FPGA 完整周期特征消息频率，包含归一化二次谐波峰值；不再统计旧 TCP 的 WaveformFeature 消息。 | 地面端每秒收到的 FPGA 周期特征消息数。归一化二次谐波峰值应由完整周期计算后传输，用于绘制随时间变化的“峰值波形”；不能从抽稀预览重新求峰值代替。其它特征仅按实际支持内容提供。 |
| 采集周期频率 | 天空端实际产生的完整 FPGA 波形周期频率，需有明确的远端计数及统计时间窗。 | 天空端每秒实际产生的完整 FPGA 波形周期数。它不同于预览接收频率、特征消息接收频率和 ADC 点采样率；不能用配置目标频率或地面接收包数代替。 |

“原始波形预览”必须在可见标签中注明 H1/H2，可使用括号或副标题；其余字段采用表中名称。既有“谐波波形”和“波形采集”等固定标题应同步替换，避免内部名称改了但最终界面仍展示旧文字。

## 交互要求

- 鼠标移到每一项的名称或数值上，都应显示对应的含义解释；两处提示一致。
- 保留远程波形抽稀和特征传输能力。抽稀降低传输点数，特征提取计算周期结果，两者不得混为同一个统计。
- “峰值波形”指逐周期归一化二次谐波峰值随时间形成的趋势，由周期特征驱动；本区域不增加重复的“峰值波形 Hz”。
- 双通道统计必须明确是所选通道、分通道还是合计，悬停提示应补充实际采用的口径。不得将两路合计频率默认为单通道频率；本需求不预先指定尚未确认的通道汇总方式。
- 未开启上传、未连接、数据过期或没有对应统计能力时，说明实际状态；缺少统计不能伪装成测得的 0.0 Hz。0.0 Hz 只用于具备有效统计条件、统计窗口内没有相应事件的情况。

## 实现边界与验收

1. 本次文档对应远程 FPGA 模式；旧远程直连模式的数据含义不应被直接覆盖，需按来源区分映射。
2. 特征统计应接入 FPGA 周期特征路径；H1/H2 预览应接入 DLIA 路径，不沿用 ADC 预览的计数。归一化预览统计实际有效更新，重复绘制同一份数据不能增加频率。
3. 当前若只有特征消息接收率，不能直接作为“采集周期频率”。应补充远端真实统计；尚未具备时显示不可用并解释。
4. 检查六项名称和顺序、H1/H2 注明、名称与数值的悬停提示。覆盖持续采集、预览上传开关、抽稀、特征持续传输、停止采集、断链及双通道场景。
5. 验证抽稀后预览点数可减少，峰值仍由完整周期计算；统计与图表数据来源一致，正常状态消息不应清空仍有效的 FPGA 波形数据。
6. 按仓库规则在 `build/Release` 完成实现后的构建及相关验证；构建与验证记录见文末。

## 补充：首页宽窗口卡片布局

状态：已实现。

- 当首页可用宽度足够，且“环境与测距”卡片已经移动到第一行时，应将 EPSILON 组合导航卡片与运动控制卡片放在同一行，避免运动控制继续独占下一行。
- 最大化窗口是典型场景，但不以最大化状态作为唯一判断条件；应根据实际可用宽度、两张卡片的最小可用宽度及间距决定是否同行。
- 宽度不足时恢复上下排列，不强行挤压内容或造成裁切、重叠。同行条件仍需包含“环境与测距”已位于第一行。
- 验收覆盖最大化、普通宽窗口及缩窄后恢复，确认两张卡片按条件同行或换行，文字和操作控件完整可见，反复调整窗口不会留下多余空白。

实现记录：

- 首页和设备页共用六项字段，不再由首页旧标题覆盖；名称与数值使用相同提示。
- FPGA 预览只累计完整、质量有效的 DLIA0/1，ADC 预览不计入；同一通道的重复周期不增加计数。归一化项只累计存在有效 H2/H1 点的预览，不以重绘计数。
- 预览与特征采用双通道合计口径，提示明确说明；频率使用最近 5 秒事件数除以 5 秒。未收到或超过 5 秒无事件显示“未收到/已过期”，断链显示“未连接”。现有状态协议不能独立确认预览上传开关，因此不会把没有预览冒充为测得的零频率，也不会推断上传已关闭。
- 特征取自 FpgaCycleFeature，完整周期峰值及抽稀/记录链路保持原实现。采集周期项明确说明缺少远端计数；未伪造实际采集频率。
- 环境卡片在首行且两张卡片最小宽度与间距能容纳时，EPSILON 和运动控制同行；缩窄恢复上下排列。
- 回归覆盖实际字段及提示、双通道统计、ADC 排除、重复预览、归一化无效点、停止后的过期状态，以及宽→窄→宽布局恢复。现场硬件采集和 SSH 不在本次验证范围。

## 1.0.30：完整周期统计与模拟数据

天空端在 USB 完整周期信号处、预览抽稀之前统计有效 DLIA0/1 周期，排除不完整、溢出、连续性错误和重复周期。每秒以实际时间窗上报 `acquisition_cycles`：`count`（十进制字符串）、`window_ms`、`rate_hz`、`scope=dlia0+dlia1`。地面端按计数除以时间窗显示双通道合计频率。统计是天空端实际收到的完整周期，不推断 USB 丢失或 FPGA 内部未上传的周期。

此项取代上文“现有协议没有计数、不可用”的实现边界；需要天空端和地面端同时更新到 1.0.30。旧天空端缺少统计仍显示不可用，链路断开或过期不显示旧值。模拟器与真实 USB 使用同一统计路径。

FPGA 模拟器的 HMP 环境温度约 23°C、湿度约 45%RH，分别以 ±0.3°C、±0.6%RH 小幅波动；地面端允许模拟来源的有效温湿度遥测进入显示，真实硬件的 HMP 支持边界不变。


1.0.30 同时修复批量断开的设备动画，并对连接期间的寄存器解析、状态广播和配置刷新做合并/缓存；动画帧只重绘按钮，不触发整页布局。设备配置页三个子卡片按各列内容确定胶囊宽度，名称左对齐、数值单位右对齐，保留两字间距；缺失的频率用 `— Hz` 表示，悬停查看具体原因。
