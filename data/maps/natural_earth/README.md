# Natural Earth Offline Basemap

This folder contains Natural Earth II 1:50m raster data with shaded relief and water.

Source: https://naturalearth.s3.amazonaws.com/50m_raster/NE2_50M_SR_W.zip

Natural Earth data is public domain.

Use `data/maps/vaporview_default.earth` in VaporView 3D Map with "加载 Earth 文件".
